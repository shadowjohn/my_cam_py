# Smoke Test Checklist

## 目標

用最短時間確認實際錄影流程可用，特別是不同電腦的音源、停止錄影、轉檔輸出與反向框選。

## 測試前

- [ ] 執行 `run.bat` 啟動程式。
- [ ] 確認 output 目錄可寫入。
- [ ] 按「重整音源」，確認系統音源與麥克風清單合理。
- [ ] 若要錄系統聲音，確認 Windows 已啟用 `Stereo Mix` / `立體聲混音` 或其他 loopback 音源。

## 基本錄影

- [ ] 反向框選錄影區域，由右下往左上拖曳。
- [ ] 錄 10 秒無聲影片，停止後確認 mp4 產生且可播放。
- [ ] 停止錄影後立即點「離開程式」，確認程式會完成收尾後關閉。

## 音源錄影

- [ ] 只勾麥克風，錄 10 秒，確認有麥克風聲音。
- [ ] 只勾系統聲音，錄 10 秒，確認有系統聲音；若無 Stereo Mix，確認程式略過系統聲音且不 crash。
- [ ] 同時勾系統聲音與麥克風，錄 10 秒，確認聲音合併正常。
- [ ] 選錯或拔掉麥克風後錄影，確認程式保留影片輸出並在 log 留下錯誤。

## 輸出與 log

- [ ] 轉檔成功後，只看到正式 `*.mp4`，沒有殘留 `*_tmp_final.mp4`。
- [ ] 若刻意中斷或造成轉檔失敗，正式輸出檔不應被半成品覆蓋。
- [ ] 檢查 `output/logs/YYYYMMDD.log`，確認有錯誤或輸出完成紀錄。
- [ ] 錄影時觀察 FPS 顯示中的 `Queue` 與 `Drop`，確認短錄影時 `Drop` 沒有持續增加。

## 建議壓測

- [ ] 30 FPS 錄 10 分鐘。
- [ ] 60 FPS 錄 10 分鐘。
- [ ] 大範圍錄影 10 分鐘。
- [ ] 錄影中切換前景視窗、播放影片、移動滑鼠，確認沒有明顯 freeze 或 crash。
- [ ] 長時間錄影後檢查 log，若有 `Frame queue dropped`，記錄當時 FPS、錄影範圍與是否同時錄音。
